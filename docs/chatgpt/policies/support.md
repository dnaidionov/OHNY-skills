# Ask OHNY support

**Prepared page copy — not yet published as a separate page.**

Ask OHNY is an unofficial guide maintained by Dmitry Naidionov. For a bug or a suggestion, [open an issue in the project tracker](https://github.com/dnaidionov/OHNY-skills/issues). Reading existing reports is public; creating an issue requires a GitHub account.

Include your app and version, whether you typed or used voice, the general question, and what went wrong. A redacted screenshot or approximate festival location can help. Never post passwords, email addresses, private locations, ticket barcodes, payment details, or other personal information in an issue. No response time is guaranteed.

If the guide cannot see live information, check [OHNY's official lineup](https://ohny.org/festival/lineup) before traveling. For ticket, admission, venue or check-in questions, contact OHNY or the relevant venue; this project cannot change those arrangements.

ChatGPT phone-only installation and voice behavior are still being verified. A desktop development connection is not evidence that a first-time phone visitor can install the guide.

For privacy requests containing personal details, do not use a public issue. The publisher must supply a private contact route before inviting those requests.
